# 👾 MYK Cyberpunk Galaga
**By Muhammed Yusuf (Age 12) | Made in Turkey 🇹🇷 with Claude AI**

A native iOS retro space shooter built entirely in **SwiftUI**.

- **Custom Engine:** 120Hz software pixel rendering (no 3rd-party engines).
- **Dynamic Island:** Live Activity tracking for scores and bosses.
- **8-Bit Audio:** Procedurally synthesized chiptunes via `AVAudioEngine`.
- **Features:** 10 unique ships, boss fights, and retro CRT scanlines.
