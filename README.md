#  MYK Cyberpunk Galaga
**Muhammed Yusuf (12 Yaşında) tarafından | Claude AI ile Türkiye'de geliştirildi**

Tamamen **SwiftUI** ile geliştirilmiş, yerel bir iOS retro uzay nişancılık oyunu.

- **Özel Oyun Motoru:** 120Hz yazılımsal piksel işleme (üçüncü taraf motorlar kullanılmadı).
- **Dynamic Island:** Skorlar ve bölüm sonu canavarları (boss) için Canlı Etkinlik (Live Activity) takibi.
- **8-Bit Ses:** `AVAudioEngine` aracılığıyla prosedürel olarak sentezlenen chiptune müzikler.
- **Özellikler:** 10 benzersiz uzay gemisi, bölüm sonu canavarı savaşları ve retro CRT tarama çizgileri.
